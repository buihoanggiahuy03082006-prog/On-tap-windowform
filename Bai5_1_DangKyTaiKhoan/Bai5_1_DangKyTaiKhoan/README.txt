BÀI 5.1 - FORM ĐĂNG KÝ TÀI KHOẢN VÀ BẮT LỖI GIAO DIỆN

Công nghệ: C# Windows Forms, .NET 10.

Cách mở:
1. Giải nén thư mục Bai5_1_DangKyTaiKhoan.
2. Mở file Bai5_1_DangKyTaiKhoan.csproj bằng Visual Studio 2022 có hỗ trợ .NET 10.
3. Nhấn F5 để chạy chương trình.

Ghi chú:
- Giao diện được tạo bằng code trong FormDangKy.cs, không cần kéo thả control.
- Các TextBox mật khẩu đã bật UseSystemPasswordChar.
- ErrorProvider tên epCheck hiển thị lỗi cạnh control tương ứng.
- Nút Đăng Ký kiểm tra tên đăng nhập, mật khẩu, xác nhận mật khẩu, tuổi >= 18 và điều khoản.
- Nút Làm Mới xóa dữ liệu và xóa thông báo lỗi.
